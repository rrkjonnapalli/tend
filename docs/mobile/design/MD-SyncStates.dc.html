Sync on the menu button

A dot on the corner button shows the state. Open the menu and the sync icon takes the same colour; tap it to act.

IdleNo dot. Sync now sits in the menu with the last time.
SyncingViolet dot.
FailedRed dot. Sync in the menu opens Settings › Sync with the error.
Needs a new tokenOrange dot. Sync in the menu opens the token sheet.
