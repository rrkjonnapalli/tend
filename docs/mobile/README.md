# Tend mobile kit

- `tend-mobile-spec.md`: the spec and the mobile build plan (P1–P8). Read this first.
- `screens/`: screenshots of every mobile screen (390×844 @2x). Match these.
- `design/`: the mockup sources (`.dc.html`) with `tend-app.css` and `tend-mobile2.css`. Reference only; class names and spacing are worth reusing, the markup is not app code.

For Claude Code: put this folder in the repo as `docs/mobile/`, then ask
"Read docs/mobile/tend-mobile-spec.md, then do P1."
